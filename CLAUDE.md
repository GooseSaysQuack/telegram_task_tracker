# Telegram Task Tracker

## Стиль ответов
- Отвечай кратко, на русском.
- Без вступлений, пересказа задачи, похвалы и итоговых резюме.
- Только рабочий код и минимум пояснений (1–2 строки, если без них нельзя).
- Не дублируй код целиком — показывай только изменённые фрагменты.
- Не предлагай альтернативы и улучшения, если не просили.
- Вопрос задавай, только если без ответа нельзя продолжить.

## Код
- Самое простое работающее решение; без лишних абстракций и зависимостей.
- Комментарии — только там, где логика неочевидна.
- Секреты (токен бота, OAuth-ключи) — только через `.env`, не коммитить.
